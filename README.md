# RusoReader/Ponchik

An ebook reader for Russian language learners, complete with grammar forms on demand and spaced repetition exercises for word memorization.

## Overview

This is a project I've been thinking of for quite some time, on paper it's super simple, it's literally an ebook reader with a dictionary! However, I've never been able to quite find something competely tailored to Russian, Linga and Readlang came close but they were both general language and always online. In this application the user will load an epub file, which must be in Russian or the entire thing is kind of useless, and then they can read the epub like any other epub reader but with one big difference. The user can click a word and it will be checked within the preloaded dictionary, if it is found we can view it's various word forms, translations, partners, etc. Russian has a lot of up front grammar, so I thought it would be useful for the user to see that. The dictionary used in the application was created by the excellent https://en.openrussian.org/, this application wouldn't have been possible without their hard work!

To help with remembering words I want to create exercises that acted as a companion to what the user viewed while reading. We will use a spaced repetition algorithim to give flash cards, case ending, verb partner matching, fill in the blank, and various kinds of exercises to further remember the words found in the users reading.

---

## Features

- Russian epub with with built in grammar form dictionary
- Exercises based on the words you've read
- Offline First!
